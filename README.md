# Gestión de Datos de Países en Python
------------Instrucciones de uso---------------
Este programa permite almacenar y gestionar información sobre distintos países mediante un archivo CSV.

Se incluye un archivo CSV con algunos datos precargados para facilitar las pruebas y el uso inicial del sistema. Sin embargo, si el usuario lo desea, puede eliminar dicho archivo y el programa seguirá funcionando correctamente, creando uno nuevo cuando sea necesario.


1. Cargar paises

el programa preguntara por los datos de un pais:

* poblacion
* nombre
* continente
* superficie

aunque si desea regresar al menu sin añadir nada, simplemente se debe presionar "-"

no se permiten añadir paises ya existentes al archivo

2.Actualizar un pais

El programa solicitará el nombre de un país. Se permite realizar búsquedas parciales.

Si el país es encontrado, se mostrará un menú con las opciones disponibles para modificar sus datos. Una vez realizado el cambio, el archivo CSV será actualiszado automáticamente.

3.Buscar

El programa solicitará el nombre de un país. Se permite realizar búsquedas parciales.

Si se encuentran coincidencias, se mostrará una lista de resultados. Al seleccionar un país, se desplegará toda la información almacenada sobre él.

4.Filtrar pais por tipo

Permite filtrar los países según alguno de los siguientes criterios:

* Continente
* rango de poblacion
* rango de superficie

Dependiendo del criterio seleccionado, el programa solicitará los parámetros necesarios para realizar la búsqueda.

5.Ordenar paises

Permite ordenar la lista de países según alguno de los siguientes criterios:
* Nombre
* Población
* Superficie

Además, el usuario podrá elegir si desea visualizar los resultados en orden ascendente o descendente.

6.Mostrar estadísticas

Genera y muestra información estadística sobre los países almacenados, incluyendo:

* Cantidad de países por continente.
* País con mayor población.
* País con menor población.
* Promedio de población.
* Promedio de superficie.

Todos los resultados son mostrados directamente en pantalla.
